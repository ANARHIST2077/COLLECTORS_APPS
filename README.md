# Hot Wheels Collection

Приложение для учёта коллекции машинок Hot Wheels для Windows (Electron) и Android (Capacitor) — один код интерфейса, один формат данных.

## Возможности

- Гараж: вкладки «Машинки / По годам / Избранное», сортировка, фильтр по году, поиск
- Карточки: название, год реальной машины, год модельки, стоимость (₽), несколько фото
- Избранное: радужная рамка, избранные всегда сверху
- Фото листаются пальцем, порядок меняется перетаскиванием (мышью и пальцем)
- Статистика: количество, стоимость, распределение по годам, самые дорогие
- Синхронизация ПК ↔ телефон через приватный репозиторий GitHub
- Выгрузка и загрузка коллекции файлом (вместе с фото)

## Скачать

В [Releases](https://github.com/ANARHIST2077/COLLECTORS_APPS/releases):

- `HotWheels-Collection-<версия>-portable.exe` — Windows, без установки
- `HotWheels-Collection-<версия>.apk` — Android (установка из файла: разрешить «Установку неизвестных приложений»)

## Синхронизация через GitHub

1. Создать **приватный** репозиторий (например, `hotwheels-data`). Публичный приложение не примет — коллекция была бы видна всем.
2. Создать токен: GitHub → Settings → Developer settings → Fine-grained tokens → доступ только к этому репозиторию, право **Contents: Read and write**.
3. В приложении: Настройки → Синхронизация через GitHub → репозиторий и токен → «Сохранить доступ».
4. На устройстве с актуальной коллекцией — «Отправить на сервер», на другом — «Обновить с сервера».

Побеждает последняя отправка: изменения с двух устройств не сливаются. Перед заменой коллекции с сервера текущая сохраняется в `collection.prev.json`.

Без интернета коллекцию можно перенести файлом: «Выгрузить коллекцию» на одном устройстве → передать файл → «Загрузить коллекцию» на другом.

## Запуск из исходников

Нужен [Node.js](https://nodejs.org/).

```
npm install
npm start
```

Сборка exe: `npm run dist` → `dist\HotWheels-Collection-<версия>-portable.exe`.

## Устройство

```
vite.config.mjs      сборка интерфейса в www/ (общий для ПК и Android)
main.js              окно Electron
main-storage.js      работа с диском (main-процесс)
preload.js           мост: интерфейсу доступны только функции хранилища
index.html, style.css
renderer.js          точка входа интерфейса (Vue 3)
src/App.vue, src/components/   экраны и панели
src/collection.js    коллекция и все действия с ней
src/sync.js          синхронизация через GitHub
src/core/            модель машинки, миграция форматов (чистый JS)
src/storage/         хранилище: electron-storage.js (ПК), capacitor-storage.js (Android)
android/             проект Android (Capacitor)
```

## Где хранятся данные

На ПК коллекция сохраняется не в папке проекта, а в профиле пользователя:

```
%APPDATA%\hotwheels-app\collection.json
%APPDATA%\hotwheels-app\images\
```

С версии 2.0 формат данных новый (`collection.json`). При первом запуске старый `hotwheels_data.json` автоматически переводится в новый формат; перед этим он и папка `images` копируются в `backup-<дата>`. Сам старый файл не изменяется.

На Android коллекция хранится во внутренней папке приложения и удаляется вместе с ним — перед удалением приложения выгрузите коллекцию.
